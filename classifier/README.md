# Классификатор обращений

Скрипт читает `messages.txt` и для каждого сообщения определяет категорию
(`справка` / `жалоба` / `другое`) и пишет короткий черновик ответа на русском.

## Запуск

```bash
python3 classify.py
```

Нужен Python 3.10+. Зависимостей нет.

## Как устроено

Правила по ключевым словам (без LLM и внешних API):
- **жалоба** — очередь, холодная еда, пропал Wi‑Fi и т.п.
- **справка** — как получить, где парковка, документы
- **другое** — всё остальное (например, запись на консультацию)

## Результат

Для пяти сообщений из задания:

| # | Сообщение | Категория |
|---|-----------|-----------|
| 1 | Как получить справку о месте учёбы? | справка |
| 2 | В столовой очередь, еда холодная. | жалоба |
| 3 | Хочу записаться на консультацию завтра. | другое |
| 4 | Пропал Wi-Fi в корпусе В. | жалоба |
| 5 | Где парковка для гостей? | справка |
