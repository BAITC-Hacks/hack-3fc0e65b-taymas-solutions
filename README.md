# Чат-бот для репетиции хакатона

Простой чат-бот в терминале, который отвечает на 5 основных вопросов о репетиции:
- Время проведения
- Состав команды
- Выбор трека
- Сдача решения
- Призы

Бот использует поиск по ключевым словам для подбора наиболее подходящего ответа. Если вопрос не распознан, бот честно отвечает «не знаю».

## Как запустить

1. Убедитесь, что у вас установлен Python (версия 3.6 или выше).
2. Откройте терминал в папке проекта.
3. Запустите скрипт командой:
   ```bash
   python bot.py
   ```
4. Задавайте вопросы! Для выхода напишите `выход`.

## Что получилось

Реализован легковесный скрипт на Python без сторонних зависимостей (RAG, ML-модели или базы данных не требуются, используется только стандартная библиотека).
База вопросов и ответов хранится в простом текстовом файле `faq.txt`, который легко редактировать и расширять.
Бот сначала ищет совпадения по предопределенным ключевым словам, а затем (если ничего не найдено) пытается найти пересечения слов пользовательского ввода со словами из вопросов в `faq.txt`.
