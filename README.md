# Репозиторий команды

В этом репозитории находятся решения двух задач для хакатона.

## 1. Чат-бот для репетиции (bot.py)
Простой чат-бот, который отвечает на 5 основных вопросов о репетиции (время, команда, трек, сдача, призы). Использует поиск по ключевым словам.

**Как запустить:** 
```bash
python bot.py
```
*База знаний хранится в `faq.txt`*

## 2. Классификатор обращений (classifier.py)
Скрипт разбирает 5 готовых обращений из файла `messages.txt` и для каждого выдает категорию и черновик ответа.

**Как запустить:**
```bash
python classifier.py
```

### Что получилось
Реализован легковесный классификатор на Python. Использование RAG или сложных ML-моделей не потребовалось — правила заданы через ключевые слова в самом скрипте. При запуске скрипт выводит в консоль исходное обращение, категорию (Справка / Жалоба / Другое) и предложенный черновик ответа на русском языке. Скрипт отрабатывает за доли секунды и полностью решает поставленную задачу.
